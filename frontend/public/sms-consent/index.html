SMS Opt-In Screen

Reference page for carrier / messaging-provider review · Last updated: August 14, 2026

GroveIQ is a private, single-operator home monitoring application, not a public consumer product with self-service signup — its dashboard requires SSO login (Cloudflare Access) and cannot otherwise be browsed. This page is published without login specifically so reviewers can verify the exact SMS/MMS opt-in flow used inside the application.

The screenshot below is the real, unmodified opt-in screen at https://grove-iq.com/settings/notifications, shown as it appears immediately after a user logs in and before entering a phone number: a mobile number field, and an unchecked-by-default consent checkbox with the full disclosure text.

Captured directly from the live opt-in screen. The checkbox is unchecked by default; the screen states a user can verify their number and use GroveIQ without checking it — SMS enrollment is entirely optional and never a condition of use.

Exact disclosure text shown next to the checkbox

Send me GroveIQ SMS/MMS notifications. By checking this box, I agree to receive recurring and event-driven text messages from GroveIQ at the mobile number provided, including plant health, sensor, irrigation, environmental/weather, security, and account alerts that I enable. Message frequency varies. Message and data rates may apply. Reply STOP to opt out or HELP for help. Consent is not a condition of purchase or use of GroveIQ. See Terms and Privacy Policy.

How opt-in works

A user reaches this screen only after authenticating into their own GroveIQ dashboard. They enter a mobile number and may optionally check the consent checkbox above before requesting a verification code. Checking the box is never required — the screen explicitly states a user can verify their number and use GroveIQ without opting in to text alerts. After verification, the user can enable specific alert categories, and can withdraw consent at any time by replying STOP to any message or by toggling it off in the same settings screen.
